<h1>Oracle Grid</h1>

# Standalone server

Components:

## Oracle Restart

* can only use for single-instance database;
* before oracle database installation we must install Oracle Restart 
* periodic status check and restart in proper order in the failure case

**IMPORTANT**: to use capabilities Oracle Restart install Oracle Grid with **Oracle Clusterware**

## Oracle Automatic Storage Management

* can be used with single-server installation and Oracle Real-application Cluster
